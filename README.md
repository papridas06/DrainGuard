# 🌧️ DrainGuard
### Drainage Risk Screening & Maintenance Prioritization Prototype

**DrainGuard** is a prototype designed to support drainage risk screening and help prioritize drainage maintenance. The project aims to organize relevant information and present it in a useful format for identifying potential drainage issues.

## 📌 Project Overview

DrainGuard explores how technology can support drainage infrastructure monitoring and maintenance planning. The prototype provides a foundation for analyzing drainage-related information and supporting maintenance prioritization.

## ✨ Key Features

- 🌧️ Drainage risk screening
- 📊 Risk assessment and maintenance prioritization
- 🗂️ Organized knowledge base

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/papridas06/DrainGuard
```

### 2. Navigate to the project directory

```bash
cd DrainGuard
```

### 3. Create a virtual environment (recommended)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the application

If `app.py` is a Streamlit application, run:

```bash
streamlit run app.py
```

Otherwise, use the command appropriate for your application's framework.
